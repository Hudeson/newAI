# 项目整体计划

> 项目：企业级知识库 Agent 平台（`newAI`）  
> 定位：多租户文档中台 × 权限可控 RAG × 自动学习总结 × 可审计 Agent  
> 本文是**项目级总计划**；近端落地步骤见 [`execution-plan.md`](./execution-plan.md)，架构见 [`technical-architecture.md`](./technical-architecture.md)。

---

## 1. 项目一句话

建设一套**可私有化部署**的企业知识库 Agent：支持文档上传/连接器同步、自动学习总结、带引用问答与工具编排，并从第一天起具备租户隔离、ACL、审计与可扩展运维能力；个人/小团队通过 profile 收缩同一套架构。

---

## 2. 成功标准（项目级）

| 维度 | 达标 |
|------|------|
| 产品 | 上传 → 学习报告 → 带引用问答主路径可用；支持空间与权限 |
| 隔离 | 跨租户可见性事件 = 0；自动化隔离套件长期守门 |
| 企业就绪 | SSO（OIDC）、配额、审计导出；SCIM/连接器可按需启用 |
| 工程 | Compose 可本地复现；Helm 可企业部署；核心 SLO 可观测 |
| 演进 | personal → team → enterprise 无需推倒数据模型 |

---

## 3. 范围

### 3.1 In Scope

- 多租户 / Workspace / RBAC + 文档 ACL  
- 上传摄入（md/txt/pdf/docx 等）、异步解析与向量化  
- 自动学习总结（摘要/大纲/要点/标签/知识卡片）与发布策略  
- 混合检索 + 带引用问答 + Agent 工具编排  
- LLM Gateway、配额、审计、基础管理台  
- SCIM、服务账号、内容连接器（至少 1～2 个源）  
- 运维：SLO、备份/DR 策略、Runbook 大纲落地  

### 3.2 Out of Scope（本项目周期不做）

- 完整协作编辑器（Notion 替代）  
- 公网 C 端增长型 SaaS 运营体系（可先私有化/专有云）  
- 全网自动爬取  
- 原生移动 App  
- 复杂双向写回源站（连接器默认只读入站）

## 4. 阶段总览（里程碑）

```
M0 设计基线 ──▶ M1 隔离竖切 ──▶ M2 学习+问答 ──▶ M3 Agent+治理
                                              ──▶ M4 企业加固
                                              ──▶ M5 规模与增强
```

| 里程碑 | 主题 | 关键交付物 | 关门验收 |
|--------|------|------------|----------|
| **M0** | 设计与工程基线 | 架构/数据/API/运维/连接器文档；执行计划；仓库骨架与 Compose | 文档齐套；依赖可拉起；healthz 通 |
| **M1** | 身份 + 上传入库 | OIDC/本地登录；预签名上传；Parse/Embed；ACL；双租户测试 | T1–T6 隔离套件全绿 |
| **M2** | 学习总结 + 安全问答 | Learn Worker；学习报告；Search/Ask+引用；LLM Gateway 初版；基础 Web | 上传后自动报告；问答带合法引用；隔离仍绿 |
| **M3** | Agent + 治理 | 工具白名单 Agent；配额/用量；管理台；SCIM/服务账号；首个连接器 | 复合任务可跑；配额可拒；目录供给可用 |
| **M4** | 企业加固 | 审批发布；敏感级模型路由；更多连接器；审计导出；备份演练 | 合规空间可审批；DR 演练记录合格 |
| **M5** | 规模与智能 | 多区域/只读副本；评测门禁 CI；成本优化；图谱（[`knowledge-graph.md`](./knowledge-graph.md)）/多模态（可选） | 容量与成本指标达标；评测回归稳定 |

**当前进度**：M0 文档与计划 **基本完成**；工程骨架与 M1 **未开始**（见执行计划 E0）。

## 6. 工作流与依赖

```
文档冻结(M0)
    │
    ▼
平台依赖 Compose（PG/Redis/Qdrant/MinIO）
    │
    ▼
身份租户 ──▶ 上传对象存储 ──▶ Worker 解析嵌入 ──▶ ACL/隔离测试(M1)
                                                      │
                                                      ▼
                                              学习 + RAG 问答(M2)
                                                      │
                              ┌───────────────────────┼───────────────────────┐
                              ▼                       ▼                       ▼
                           Web 完善              Agent/配额/SCIM          连接器(M3)
                              │                       │                       │
                              └───────────────────────┴───────────────────────┘
                                                      │
                                                      ▼
                                         审批/敏感路由/DR 演练(M4)
                                                      │
                                                      ▼
                                              规模化与增强(M5)
```

**关键路径**：隔离竖切（M1）→ 问答主路径（M2）。企业连接器不阻塞 M2。

## 8. 技术基线（不变，除非 ADR 变更）

- 前端：Next.js  
- API：FastAPI  
- DB：PostgreSQL（全表 `tenant_id`）  
- 对象存储：S3 兼容  
- 向量：Qdrant  
- 队列/缓存：Redis（或 NATS）  
- 认证：OIDC；供给：SCIM  
- 模型：经 LLM Gateway（云 + 可切私有）

## 10. 质量门禁

| 门禁 | 强制点 |
|------|--------|
| 合并 M1 | 双租户隔离 T1–T6 必须绿 |
| 合并 M2 | 引用校验 + 隔离回归 |
| 合并 M3 | 工具鉴权；配额拒绝可测 |
| 发布企业版 | 备份恢复演练报告；无高危未修串租类缺陷 |

红线：**禁止无租户 filter 的向量检索合入主干**。

## 11. 风险与对策（项目级）

| 风险 | 影响 | 对策 |
|------|------|------|
| 范围膨胀（早做 Agent/连接器） | M1 延期 | 执行计划锁定 E0–E4 关门再开 E5 |
| PDF/解析质量 | 学习与检索差 | 先 md/txt + 文本 PDF；OCR 后置 |
| LLM 成本 | 预算失控 | Gateway 配额；学习异步；小模型摘要 |
| 权限漏过滤 | 串租 | filter+二次校验；隔离测试守门 |
| Embedding 换模 | 检索失效 | 版本字段 + 重建任务 |

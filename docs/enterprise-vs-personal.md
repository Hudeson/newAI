# 企业级 vs 个人版对照

本文补充主设计文档，说明「企业级优先」后与常见个人 RAG 方案的差异。

| 维度 | 个人常见做法 | 本设计（企业级） |
|------|--------------|------------------|
| 前端 | Streamlit 快速原型 | **Next.js** 为主（管理台+用户端） |
| 元数据库 | SQLite | **PostgreSQL**（全表 `tenant_id`） |
| 文件 | 本地目录 | **S3 兼容对象存储** + 存储抽象 |
| 向量 | 单 collection 无租户字段 | **payload 强制租户/空间/ACL 相关字段** |
| 权限 | 无 / 单用户 | **RBAC + 文档 ACL**；检索前过滤 |
| 认证 | API Key | **OIDC SSO**（personal 可本地账号） |
| 学习总结 | 上传即公开发布 | **draft → 审批/发布（空间策略）** |
| 任务 | 请求内同步 | **队列 + Worker**，可扩缩容 |
| 模型 | 直连厂商 | **LLM Gateway**（路由/预算/审计） |
| 部署 | docker compose 单机 | Compose（dev）/ **Helm（企业）** + profile |
| 审计 | 应用日志 | **只追加 audit_events + 计量账本** |

不变的产品内核：上传文档、自我学习总结、带引用问答、Agent 工具。
